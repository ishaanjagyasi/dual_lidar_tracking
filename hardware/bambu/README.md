# Bambu Studio presets (0.4 nozzle, PLA)

| | |
|---|---|
| `LiDAR jig @BBL A1.json` | A1 |
| `LiDAR jig @BBL X1C.json` | X1 Carbon (also X1, X1E, P1S) |
| `... + supports ...` | same, with supports (not needed, adds ~1h 17m) |

**Install:** *File → Import → Import Configs…*, pick the file, then choose it in
the Process dropdown. Any PLA filament profile works.

- Put **both copies on one plate**. The thin posts need the extra cooling time.
- On the X1C, open the door and take the top glass off.
- X1C presets have pairs of values (one per extruder). That's on purpose.
